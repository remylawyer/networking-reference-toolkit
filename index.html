About this project

This toolkit was developed with assistance from AI tools for drafting, organisation and refinement. The content was reviewed by the author against their own networking knowledge and learning, with the aim of improving accuracy, clarity and practical usefulness.

The resource is subject to ongoing technical review, fact-checking against authoritative documentation, and refinement based on external feedback. Readers should verify critical procedures against current vendor documentation and test configurations in an appropriate lab or authorised environment.

Every factual claim is checked against primary sources — RFC Editor, IANA registries, Cisco, Microsoft and vendor documentation — and external links are re-tested at each release. Revision 1.3 · Last reviewed 12 October 2026.

Educational reference only. Platform syntax, features, standards and supported distances vary by device, software release, policy and installation conditions. Commands should be used only on systems you are authorised to inspect or administer.
